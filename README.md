# AI-Chatbot
# AI Assistant using LangChain & Gemini

A simple AI assistant built using **LangChain**, **Google Gemini API**, and **Python**.

The assistant can:
- Answer user queries
- Use tools/functions
- Fetch the current date
- Generate AI responses using Gemini

---

## Technologies Used

- Python
- LangChain
- Google Gemini API
- dotenv

---

## Project Structure

```bash
AI_Assistant_Project/
│
├── main.py
├── .env
├── requirements.txt
└── README.md
```

---

## Installation

Install required libraries:

```bash
pip install langchain langchain-google-genai python-dotenv
```

---

## Setup

Create a `.env` file:

```env
GOOGLE_API_KEY=your_api_key
```

---

## Run the Project

```bash
python main.py
```

---

## Features

- AI chatbot using Gemini
- Tool calling support
- Current date function
- Environment variable security
- Clean command-line interaction
